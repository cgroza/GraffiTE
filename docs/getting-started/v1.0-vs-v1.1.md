# v1.0 vs v1.1

!!! info "Applies to GraffiTE v1.1"
    Verified against `v1.1dev` at commit `4c8e385`. The
    [2024 paper](https://www.nature.com/articles/s41467-024-53294-2) describes v1.0.

The paper (Groza, Chen, Wheeler et al., *Nature Communications* 2024) describes v1.0, which is
what the `main` branch still holds. This site documents v1.1. If you come from the paper, or
from the [README on `main`](https://github.com/cgroza/GraffiTE/blob/main/README.md), this page
lists what moved. Each row was checked against the v1.1 code; the v1.0 column comes from the
README on `main`.

---

## Command line

| | v1.0 | v1.1 |
|---|---|---|
| Read sets to genotype | `--reads reads.csv` | `--genotype_with reads.csv` <span class="src">`nextflow.config:40`</span>. A v1.0 command line with `--reads` is not an error; Nextflow ignores the parameter and the pipeline looks for the default `reads.csv` instead. The hyphenated `--genotype-with` of the v1.1 README on `main` behaves the same way: Nextflow stores it as `genotypeWith` and `genotype_with` keeps its default (checked with Nextflow 26.04.6). |
| `--mammal` | Turns on the L1 5′ inversion and SVA VNTR checks. | Accepted and inert. Both checks run on every dataset; the script only prints a notice <span class="src">`bin/repmask_vcf.sh:112-116`</span>. |
| SV inputs | `--assemblies`, `--longreads`, `--bams`, `--vcf`, `--RM_dir`, `--graffite_vcf` | Adds `--pav` (the PAV caller), `--svs` (per-sample VCFs into the merge), `--graph`, `--graph_alignments`, `--vcfs` and `--graph_method precomputed` for reusing a graph or alignments. |
| Repeat-span filter | `total_match_span` ≥ 0.80, fixed. | `total_repeat_span` (RepeatMasker hits plus ULTRA tandem repeats, non-redundant) against `--repeat_span_cutoff`, default `0.80` <span class="src">`nextflow.config:56`</span>. |
| Aligner for assemblies | minimap2 | minimap2 or winnowmap (`--aligner winnowmap`), plus `--break_scaffolds` to split scaffolds at runs of N. |
| Human data | none | `--human` and its whitelists and thresholds; the HERV-K classifier parameters. See [Human MEIs](../guides/human-mei.md). |
| Methylation | none | `--epigenomes`, `--code`, `--motif`, `--lifted`, `--bed`. See [Methylation](../guides/methylation.md). |
| `--vcf` with a discovery flag | Crashed on an undefined channel. | Refused up front with a message <span class="src">`main.nf:54-57`</span>. |
| `--tsd_win` | Sized the flanks, but the matcher scored against a fixed 30 bp. | Honoured end to end <span class="src">`bin/TSD_Match_v2.sh:9`</span>. |

Every current parameter is on [Parameters](../reference/parameters.md).

## Annotation

| | v1.0 | v1.1 |
|---|---|---|
| Fragment stitching | OneCodeToFindThemAll on the RepeatMasker output. | RepeatMasker `.out` read directly; OneCode removed <span class="src">`bin/repmask_vcf.sh:55`</span>. `fragmts`, `RM_hit_IDs` and `n_hits` keep their meaning. |
| Tandem repeats | not annotated | ULTRA runs on every candidate; `ULTRA_TR` and `ULTRA_TR_span` fields. |
| polyA tails | not annotated | `polyA=TRUE/FALSE/NA` on single-hit records. |
| L1 5′ inversion | `mam_filter_1=5P_INV`, only with `--mammal` | `L1_5PINV`, always present, holding the hit ID of the inverted fragment or `None`. |
| SVA VNTR-only polymorphisms | `mam_filter_2=SVA_VNTR`, only with `--mammal` | The hit is renamed with a `(VNTR_only)` suffix in `repeat_ids` and its class becomes `Simple_repeat`; no separate field. |
| RepeatMasker `--nolow` | on | removed (01/01/25), so low-complexity stretches inside consensus sequences no longer produce spurious hits. |
| RepeatMasker coordinates | 1-based | 0-based, so hit lengths are exact (10/21/24). |
| Subsets | none | `pangenome.trusted.vcf` (or `pangenome.human.vcf` with `--human`) and presence-absence TSVs beside `pangenome.vcf`. |

## Target site duplications

| | v1.0 | v1.1 |
|---|---|---|
| Which records | `n_hits=1`, plus L1s flagged `5P_INV` | every record that passes the repeat-span filter |
| Method | blastn / EMBOSS alignment of the flanks | exact seed-and-extend match, `exact_match.py`, seeds of 4 bp, TSD length 4 to 20 bp |
| Output | `TSD=left,right` | one `INFO/TSD` field with the 5′ and 3′ copies, only when the match passes |
| Pass rule | alignment score | `score = min(a, b) ≤ 5`, the distance of the hit from the junction |

The scoring is on [Target site duplications](../background/tsd.md).

## Genotyping

| | v1.0 | v1.1 |
|---|---|---|
| `vg call` | `vg call -a` | `vg call -a -A`, then `bcftools norm -m-` to one ALT per record <span class="src">`module/main.nf:811-812`</span> |
| Sex chromosomes | no ploidy setting | `-R chrX:1,chrY:1`: haploid calls on `chrX` and `chrY` by contig name <span class="src">`module/main.nf:811`</span>. See [Stage C: genotyping](../guides/genotyping.md). |
| PanGenie | run on `pangenome.vcf` directly; genotypes merged as written | `PanGenie-index` built from a `bcftools norm -m+` VCF, and the genotypes split back to one ALT per record before the merge <span class="src">`module/main.nf:701-705`</span>. Record counts on PanGenie runs differ from earlier `v1.1dev` commits, which merged the multi-allelic file. |

## The paper's modes

The paper names nine modes. This is the table from the v1.0 README with the v1.1 spelling of
the genotyping flag.

| Mode | v1.1 arguments | Discovery from | Genotyped with |
|---|---|---|---|
| GT-sv | `--assemblies a.csv --genotype false` | assemblies | nothing |
| GT-sn | `--longreads lr.csv --genotype false` | long reads | nothing |
| GT-svsn | `--assemblies a.csv --longreads lr.csv --genotype false` | both | nothing |
| GT-sv-PG | `--assemblies a.csv --genotype_with sr.csv` | assemblies | short reads, PanGenie |
| GT-sn-PG | `--longreads lr.csv --genotype_with sr.csv` | long reads | short reads, PanGenie |
| GT-svsn-PG | `--assemblies a.csv --longreads lr.csv --genotype_with sr.csv` | both | short reads, PanGenie |
| GT-sv-GA | `--assemblies a.csv --genotype_with lr.csv --graph_method graphaligner` | assemblies | long reads, GraphAligner |
| GT-sn-GA | `--longreads lr.csv --genotype_with lr.csv --graph_method graphaligner` | long reads | long reads, GraphAligner |
| GT-svsn-GA | `--assemblies a.csv --longreads lr.csv --genotype_with lr.csv --graph_method graphaligner` | both | long reads, GraphAligner |

`--graph_method pangenie` is the default and is left out of the PG rows.

## Numbers from the paper

The resource table in the v1.0 README (human, *Cannabis sativa* and *Zea mays*) was measured on
v1.0 and is not repeated here. It is still readable on
[`main`](https://github.com/cgroza/GraffiTE/blob/main/README.md#resource-usage-examples).
v1.1 changes the annotation stage (ULTRA, more TSD searches), so treat those figures as a floor.
