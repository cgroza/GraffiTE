# v1.0 vs v1.1

!!! info "Applies to GraffiTE v1.1"
    Verified against `v1.1.0.0` at commit `68ddc42`. The
    [2024 paper](https://www.nature.com/articles/s41467-024-53294-2) describes the code at the
    `publication` tag, which predates v1.0.

The paper (Groza, Chen, Wheeler et al., *Nature Communications* 2024) describes the code at the
[`publication`](https://github.com/cgroza/GraffiTE/tree/publication) tag, commit `8f44c22` of
2024-05-29. `main` has 111 more commits after the tag, up to `f37674b` of 2026-01-15, and that
last commit before v1.1 is v1.0, tagged `v1.0.0.0`. If you read the README on `main` before the
v1.1 release, you read about v1.0. To run v1.0, pass `-r v1.0.0.0` to `nextflow run`. This site
documents v1.1.

Each table below has a column for the paper, one for v1.0 and one for v1.1. The READMEs of the
first two are at the [`publication`](https://github.com/cgroza/GraffiTE/blob/publication/README.md)
and [`v1.0.0.0`](https://github.com/cgroza/GraffiTE/blob/v1.0.0.0/README.md) tags.
**New in** names the version that brought a change: **v1.0** for a change made after the paper,
which v1.1 keeps; **v1.1** for a change in this release; **v1.0, v1.1** for a row that changed
twice. **none** marks a row that is the same in all three. Citations without a prefix point to
the v1.1 code, and those prefixed `publication:` or `f37674b:` to the paper or v1.0 code.

## Modes from the paper

The README at the `publication` tag lists the nine modes the paper refers to
<span class="src">`publication:README.md:322-334`</span>. This is that table with v1.1 arguments. With the
paper code or v1.0, write `--reads` where the table has `--genotype_with`.

| Mode | v1.1 arguments | Discovery from | Genotyped with |
|---|---|---|---|
| GT-sv | `--assemblies a.csv --genotype false` | assemblies | nothing |
| GT-sn | `--longreads lr.csv --genotype false` | long reads | nothing |
| GT-svsn | `--assemblies a.csv --longreads lr.csv --genotype false` | both | nothing |
| GT-sv-PG | `--assemblies a.csv --genotype_with sr.csv` | assemblies | short reads, PanGenie |
| GT-sn-PG | `--longreads lr.csv --genotype_with sr.csv` | long reads | short reads, PanGenie |
| GT-svsn-PG | `--assemblies a.csv --longreads lr.csv --genotype_with sr.csv` | both | short reads, PanGenie |
| GT-sv-GA | `--assemblies a.csv --genotype_with lr.csv --graph_method graphaligner` | assemblies | long reads, GraphAligner |
| GT-sn-GA | `--longreads lr.csv --genotype_with lr.csv --graph_method graphaligner` | long reads | long reads, GraphAligner |
| GT-svsn-GA | `--assemblies a.csv --longreads lr.csv --genotype_with lr.csv --graph_method graphaligner` | both | long reads, GraphAligner |

`--graph_method pangenie` is the default in all three versions, so the PG rows leave it out.

## Resource figures

We added a table of measured resources (human, *Cannabis sativa* and *Zea mays*) to the README
on `main` on 2024-09-06 (`d833ca9`), after the paper release. Read it in the
[v1.0 README](https://github.com/cgroza/GraffiTE/blob/v1.0.0.0/README.md#resource-usage-examples);
this page does not repeat it. The README at the `publication` tag gives only rough figures for
human chromosome 1 and *Drosophila melanogaster*. The table went into the README before we split
RepeatMasker by contig (v1.0) and before we added ULTRA to that step and an index to PanGenie
(v1.1), so its RepeatMasker and PanGenie rows may not hold for either version. For v1.1, see
[Resources and scaling](../guides/resources.md).
